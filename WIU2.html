About the game

Carnival Quest is a lively 3D carnival ground simulation game featuring a central hub that connects four distinct minigame stalls. Before entering the hub, players speak to a ticketmaster who gives them a stamp card that fills out as they win games. To secure victory, players must clear the minimum score threshold for all four carnival activities.

Built as part of the DX1125 Computer Graphics Simulation module, the environment was collaboratively designed by the entire team using a custom OpenGL and C++ framework.

What I built

Designed and implemented the Can Knocker minigame, where players throw a ball at moving stacks of cans to knock down as many as possible within a 2-minute time limit.
Developed the base physics engine handling real-time velocity calculations, directional trajectories, and responsive bounding properties for all simulated objects.
Programmed 3D collision detection supporting Sphere-to-Sphere and AABB-to-AABB intersection calculations as narrow-phase collision layers.
Authored collision resolution routines determining velocity feedback and bounce distribution to simulate structural object tipping and impact responses.
Engineered a Game Object System providing automated rendering context pipelines and simultaneous collision boundary management for all scene entities.
Created a real-time Scene Editor for modifying positions, scaling vectors, asset definitions, and physics attributes on the fly during development.
Built the Player class managing 3D first-person camera movement, look-around input, navigation logic, and user button state triggers.
Architected the Scene Manager and core backend loops handling centralized scene state switching, Save/Load progress serialization, a particle system, main menu, and button UI.
Executed final multi-module code integration, assembling all decoupled framework systems alongside the core graphical interface into a cohesive build.

Challenges & Solutions

Challenge: Implementing 3D AABB collision detection from scratch inside a custom engine without access to a ready-made physics library.
Solution: Researched YouTube tutorials and online technical documents to fully understand how AABB intersection could be implemented and resolved in 3D space.

Outcome

Delivered a modular 3D simulation framework underpinning the entire project, with stable collision systems, a working scene editor, save/load support, and a complete particle and UI pipeline. The Can Knocker minigame shipped as a fully playable, physically simulated carnival experience within the two-week sprint.
