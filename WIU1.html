About the game

Detective Dexter and the Sun Snatcher is a real-time dungeon crawler RPG built using a stylized text-art aesthetic. Players guide Detective Dexter through Vector's trap-filled mansion to disable the Sun Snatcher 9000 machine before time runs out.

The project relies on an interactive, branching narrative loop where tactical combat performance and exploration paths, including secret rooms, gun upgrades, keycards, and boss battles, lead to five completely unique story endings.

What I built

Core game loop framework integrating precise delta-time handling, centralized game manager tracking, and real-time user keystroke input processing.
Player movement, walls, and box entities, covering full player control and the static geometry that defines each room's navigable space.
Data-driven room generation sub-system that parses CSV files to dynamically instantiate room layouts and spawn game objects on demand.
Custom ASCII text renderer that loads raw .txt art files alongside CSV room data to compose and stream complete terminal-based environment structures.
Comprehensive 2D collision system resolving boundary intersections across walls, moving entities, active bullet projectiles, interactive doors, and static items.
Real-time directional shooting module for both player and enemies, configuring unique projectile speeds and maximum travel ranges across the Pistol, Rifle, and Sniper weapons.
Scripted cinematic animation architecture managing frame rendering sequences for the opening entry cutscene and all five branching narrative endings.

Outcome

Successfully deployed a modular, high-performance terminal framework processing file-streamed maps and complex array transformations seamlessly. The detached data layout using CSV and text files allowed parallel asset production across the entire programming unit.
